## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```

---

## ✨ Key Features
- **Visual Delivery Progress**: Redesigned 4-stage delivery timeline with completion percentages and milestone telemetry.
- **Status at a Glance**: Clear current order status, ETA time window, courier details, and item summary.
- **Interactive Support**: Live chat support drawer, driver call/message triggers, and order issue reporting.
- **Mobile Responsive**: Fully responsive across mobile viewports (360px – 430px) and wide desktop screens.

---

## 🎯 Handled Scenarios
Easily test all three assessment situations using the top **Scenario Switcher**:
1. **Delayed Order**: Communicates severe transit delay, shows revised ETA, and offers priority expediting & delay credit.
2. **Delivered but Not Received**: Doorstep delivery proof photo, verified GPS radius, and 1-click lost package claim.
3. **Tracking Not Available Yet**: Clean warehouse fulfillment status with carrier handover countdown and SMS alert toggle.
